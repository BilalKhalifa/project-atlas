# Color Philosophy

Color communicates meaning before beauty.

Atlas uses color to guide attention, reinforce trust, and provide feedback.

Color should never compete with content.

Neutral surfaces dominate the interface.

Accent colors exist to help users, not decorate the UI.

---

### Surface-first Design

Instead of thinking:

```
Blue Button
Gray Card
White Background
```

Think:

```
Surface
↓
Elevation
↓
Content
↓
Accent
```

Like Apple, Linear, and Raycast.

---

### Color Hierarchy

```
Neutral (80%)

↓

Primary Accent (10%)

↓

Semantic Colors (10%)
```

This is why Linear feels so calm.

---

### Semantic Colors

Don't just define colors.

Define emotions.

| Color | Meaning |
| --- | --- |
| Green | Success |
| Amber | Attention |
| Red | Destructive |
| Blue | Information |

Never use red just because it "looks cool."
