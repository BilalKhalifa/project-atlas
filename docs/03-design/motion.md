## Motion Principles

Motion communicates.

Animation is a reward, not a requirement.

Motion follows attention.

Confidence over excitement.

The more focused the user needs to be, the calmer the interface becomes.

---

## Motion Hierarchy

### Functional Motion

Required for usability.

Examples:

- Loading

- Toasts

- Page transitions

- Lock / Unlock

- Copy feedback

---

### Contextual Motion

Explains relationships.

Examples:

- Morph transitions

- Expand / Collapse

- Sidebar

- Command Palette

---

### Delight Motion

Used sparingly.

Examples:

- Magnetic buttons

- Animated icons

- Hero interactions

- Success animations

---

## Motion Rules

Use morph transitions when navigating between related content.

Use magnetic effects only for primary interactive elements.

Avoid decorative animations during focused tasks.

Support prefers-reduced-motion.

Every animation should answer:

- What happened?

- Where did it go?

- Was it successful?
