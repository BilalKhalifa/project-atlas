### Typography Rules

Instead of:

```
Use bold.
```

Say:

```
Weight creates hierarchy before size.
```

Instead of:

```
Use bigger headings.
```

Say:

```
Whitespace creates hierarchy before typography.
```

These subtle principles make a huge difference.
