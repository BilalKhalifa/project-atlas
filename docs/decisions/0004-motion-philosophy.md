# Motion Philosophy

Status: Accepted

## Decision

Atlas uses motion to communicate, not decorate.

Motion is divided into:

- Functional

- Contextual

- Delight

Magnetic effects and morph transitions are allowed only when they improve understanding or provide meaningful feedback.

Animation should never distract users from security-related tasks.

## Principles

- Motion communicates.

- Animation is a reward, not a requirement.

- Motion follows attention.

- Confidence over excitement.
