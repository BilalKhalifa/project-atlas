# Login Intelligence

Status:

Research

Priority:

Future

---

## Problem

Users often forget:

- Which login method they used.

- Which Google account.

- Whether a site uses Password, Passkey, OAuth or SSO.

---

## Vision

Atlas should remember authentication context—not just credentials.

---

## Possible Metadata

- Preferred Login

- Available Login Methods

- Identity Provider

- Provider Email

- Last Used Method

- Last Used Device

- Last Used Browser

- Last Successful Login

---

## Sync

Metadata is encrypted and synced across devices.

---

## UX

Atlas may suggest:

"Continue with Google"

instead of simply showing a password.

---

## Privacy

Authentication metadata should only be stored with user consent.

Users can disable it at any time.
